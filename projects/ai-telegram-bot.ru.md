# AI Telegram-бот

Один чат, за которым стоят 18 моделей. Не нужно выбирать специализацию и не нужно учить
команды: `/start` → язык → модель → вопрос. Бот сам понимает, о чём спрашивают, и
подстраивается — в том числе когда тема внутри разговора уходит с трейдинга на рецепты и
обратно.

## Как устроено

| Слой | Отвечает за |
|---|---|
| Хендлеры | только Telegram: что нажали, что показать |
| Экраны | отрисовка, общая для команд и кнопок |
| Каталог | платформы, модели, системный промпт |
| Распознавание | картинка, презентация, файл, сложность |
| Вложения | приём фото, голоса и документов |
| Маршрутизация | тема вопроса и порядок моделей |
| Тарифы | лимиты, цены, экономика |
| Сервисы | AI, картинки, сборка, качество, подписки, платежи |
| Провайдеры | обёртки над API за общим интерфейсом |
| БД | модели и запросы |
| Админ-API | статистика и управление по HTTP |

Telegram, бизнес-логика, AI-провайдеры и база не смешиваются: хендлер не знает, какой SDK
вызывается, а провайдер не знает про Telegram. Добавить модель, провайдера, язык или тариф —
это правка одного слоя.

**312 тестов**, все без обращений в сеть. Покрывают то, что ломается молча: распознавание запросов,
экономику тарифов, лимиты Telegram, полноту переводов. Отдельный набор существует только
ради ошибок, которые стоят денег — маржа ушла в минус, младший тариф выгоднее старшего,
обещано больше картинок, чем позволяет лимит, — и прогоняется при любой правке цен.

## Два решения, которые стоит назвать

**Только официальные API.** В названиях тарифов есть «Pro», но ни аккаунты ChatGPT
Plus / Claude Pro, ни куки, ни сессионные токены нигде не используются. Этот путь нарушает
правила провайдеров и заканчивается блокировкой; платные ключи API — нет.

**Нет ключа — функция скрыта, а не сломана.** Бот запускается с одним ключом провайдера
(хватает бесплатного Gemini), а платформа без ключа просто не появляется в меню. Мёртвых
кнопок нет.

| | |
|---|---|
| Язык | Python |
| Telegram | aiogram |
| База | PostgreSQL, миграции Alembic |
| Развёртывание | Docker Compose, одной командой |
| Администрирование | HTTP API и команды в чате |
